0. 给同事的最省事 3 步

  1. 拿一把仓库专用钥匙：仓库管理员去 GitHub 生成一个仅限 wonderful-1101/jardin-gallery 单仓库、权限为 Contents: Read and write 的 Fine-Grained Token 发给同事。
  2. 浏览器直接拖（零命令）：同事打开 发布作品页，把写好的 单个 .html 文件（或整文件夹）拖进去填好标题点发布即可。
  3. 或者丢给自己的 AI 一句话自动传：把下面这句发给 Cursor / Claude / Antigravity：
请先阅读 https://wonderful-1101.github.io/jardin-gallery/docs.md 的发布规范，检查我当前的 HTML 互动作品，并用文档里的零依赖 CLI 将其推送到仓库 wonderful-1101/jardin-gallery ，我的 Token 是：<填入Token>。

1. 零依赖 CLI（支持单个 .html 或整目录）

只需本机装有 Node.js 18+，无需 npm install，通过 GitHub API 单次提交推送上线：

# 下载脚本（Mac / Linux / Git Bash）
curl -fsSL "https://wonderful-1101.github.io/jardin-gallery/cli/jardin-push.mjs" -o jardin-push.mjs

# Windows PowerShell 下载命令
# Invoke-WebRequest -Uri "https://wonderful-1101.github.io/jardin-gallery/cli/jardin-push.mjs" -OutFile jardin-push.mjs

# 推送单个 .html 文件（自动映射为入口）
node jardin-push.mjs ./my-artwork.html \
  --repo "wonderful-1101/jardin-gallery" \
  --token "你的GitHub_Token" \
  --id "aurora-drift" \
  --title "极光流影" \
  --author "同伴署名" \
  --tags "风景,鼠标互动" \
  --cover ./cover.jpg

# 或推送整个网页目录（根目录须有 index.html，内部使用相对路径 ./）
node jardin-push.mjs ./dist --repo "wonderful-1101/jardin-gallery" --token "你的GitHub_Token" --id "aurora-drift" --title "极光流影"

2. HTML 文件书写小提示

  • 同事做的如果是单文件 HTML（Canvas / WebGL / CSS / JS 都在同一个 .html 里），不用改任何东西，直接拖上去就行。
  • 如果引用了外部图片或音频，请放在同一目录并用 ./文件名 相对路径引用，千万不要写 C:\Users\... 本地绝对路径。
  • 每次上传推送到 GitHub 后，GitHub Pages 通常需要 30-60 秒完成静态构建并刷新线上画面。
